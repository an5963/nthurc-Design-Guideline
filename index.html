專案交付原則

📁

原始檔案需保留

製作原始檔（.ai / .psd / .prproj）皆須完整妥善留存公槽，以利日後改版或協同編輯

🖨️

實體輸出要注意

印刷檔務必確認「文字轉外框」、色彩模式、出血設定，並檢查使用效果是否影響輸出（如透明度/濾鏡）

Workflows

1

需求確認

歸檔與交付

常見狀況應對

大原則：遇到不清楚或不知如何處理時，先詢問凱弘或牧羣
Q1

不知道圖片製作規格時？

可先至本網站「專案類型」中查詢，如果都無類似需求或為特殊規格，可直接詢問凱弘

先查規格 ➔ 無答案問凱弘
Q2

有人想要拿中心的輔銷物？

請先查看「雲端輔銷物庫存表」，確認需拿取的品項名稱、領取數量以及存放位置，登記後再行發放

查雲端庫存表 ➔ 核對品項數量
Q3

對企劃/設計有不同想法？

歡迎主動提出！設計非常需要不同觀點碰撞，無論在排版或內容上有新靈感，都可一起討論

歡迎隨時提出想法碰撞

官網製圖

Web Graphics
🖥️ 首頁輪播圖
  • 製作尺寸：1181*448 px (輸出時選兩倍)
  • 圖檔格式：png or jpg
  • 色彩與解析度：RGB、72 dpi
  • 檔案大小：建議壓縮在 1MB 以下，確保網站載入速度
🖼️ 文章縮圖與內頁圖片
  • 文章縮圖尺寸：798*532 px (建議輸出時選兩倍)
  • 內頁圖片尺寸：寬度固定 1200 px，高度依原始照片調整
  • 色彩與解析度：RGB、72 dpi

社群圖文

Social Media
📘 Facebook 貼文
  • 單圖：1500 x 1500 px (方型)、1500 x 1875px (直方型)
  • 多圖：1500 x 1500 px (方型)
  • 色彩與解析度：RGB、72 dpi
📱 Instagram 貼文
  • 單圖&多圖：1500 x 1875px (直方型)
  • 色彩與解析度：RGB、72 dpi
💬 LINE 推播
  • 單頁訊息：1040 x 700 px 或 1040 x 1300 px 或 1040 x 1040
  • 多頁訊息：1500 x 1365 px (方型)
  • 色彩與解析度：RGB、72 dpi

簡報製作與美化

PPT / Gamma
🎯 簡報版面標準
  • 製作比例：16:9 (1920 x 1080 px)
  • 排版原則：注意圖文對齊，並善用圖表將數據可視化，避免大量文字堆疊

專案類型 ➔ 實體印刷規範

實體印刷規範

包含活動背板、海報、手舉牌、小卡等輸出物規格，輸出前請將印刷檔轉外框並確認設計效果是否影響最終製作

海報設計 (Poster)

Poster
📏 常用印製尺寸
  • A1 (全開)：594 x 841 mm (出血後 600x847mm)
  • A2 (對開)：420 x 594 mm (出血後 426x600mm)
  • A3 (四開)：297 x 420 mm (出血後 303x426mm)
  • A4 (八開)：210 x 297 mm (出血後 216x303mm)
  • 色彩與解析度：CMYK 色彩模式，解析度必須達 300 dpi
  • 出血設定：四邊各加 3 mm 出血線

手舉牌、各式小卡

Marketing Props
🏷️ 常用輔銷物類型
  • 單人手舉牌：約寬 85 x 65 cm（pvc-4色-霧p-合成版）較醒目
  • 名片：90 x 54 mm（四邊出血 1mm）
  • 節慶小卡：120 x 80 mm（四邊各留 1mm 出血）、150 x 105 mm（四邊出血 1mm）

DM 折頁

Flyer / Brochure
📄 規格要點
  • A4 雙面：210 x 297 mm (四邊出血 3mm)
  • A4 三折頁：展開尺寸 297 x 210 mm（內折頁寬度99mm）

活動大型輸出

Large Output
🎪 大型輸出要點
  • 常見尺寸：寬 300 ~ 600 cm x 高 240 cm（依活動場地丈量尺寸為準）
  • 製作比率：檔案過大可採 1:10 縮小製作（300dpi CMYK），並於檔案內標記輸出原尺寸
  • 視覺重心：主標與主視覺應放置於離地 120cm 以上之安全高度，避免被貴賓合影時遮擋
專案類型 ➔ 影音剪輯與企劃指南

影音剪輯與企劃指南

包含長影音、短影音製作與腳本常用規格

長影音 (招商影片 / 活動紀實)

🎬 規格與輸出
  • 畫面比例：16:9 橫式
  • 解析度：1920 x 1080 (FHD) 或 4K (3840x2160)
  • 幀率：29.97 fps 或 60 fps
  • 編碼格式：H.264 (.mp4)，音訊 AAC 立體聲

社群短影音 (Reels / Shorts)

⚡ 規格與安全區
  • 畫面比例：9:16 直式 (1080 x 1920 px)
  • 黃金前 3 秒：開頭建議直接破題，勾住觀眾
  • 介面安全區：字幕與重要內容應避開右側按讚列、底部描述區

腳本與分鏡企劃

📝 腳本分鏡格式
  • 【格式】：畫面描述／運鏡／視卡指示／旁白口播／字幕／配樂 說明
  • 秒數預估：標註每段預計秒數，方便對位與控制整體秒數
